# Daily Red Pokemon

An unofficial daily Pokémon browser battle inspired by Generation III.

🎮 **[Play Daily Red Pokemon](https://dailyredpokemon.org/)**

## About the game

Take on a daily battle challenge directly in your browser.

- Generation III battle mechanics
- A daily Pokémon battle challenge
- Play directly in your browser
- Progress saved locally in your browser
